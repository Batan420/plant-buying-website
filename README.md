##🌿 Plant Buying Website

A **modern and responsive Plant Buying Website** built using **HTML**, **Tailwind CSS**, and **JavaScript**.  
This project offers a smooth and elegant user experience for exploring, selecting, and buying plants online.

---

## 🚀 Features

- 🌱 **Modern UI/UX** — Clean and minimal design with smooth animations.  
- 📱 **Fully Responsive** — Optimized for all screen sizes (desktop, tablet, and mobile).  
- 🛒 **Interactive Shopping Experience** — Add to cart, browse plant categories, and view details dynamically.  
- 🔍 **Search & Filter Options** — Quickly find your favorite plants.  
- 🌼 **Fast & Lightweight** — Built with pure HTML, Tailwind CSS, and Vanilla JavaScript for top performance.  

---

## 🛠️ Tech Stack

- **HTML5** — Structure of the website  
- **Tailwind CSS** — Modern utility-first CSS framework for styling  
- **JavaScript (ES6)** — Handles interactivity and dynamic UI updates
